- Verilog: `lif_neuron` module (3 weighted inputs, parameters for weights) instantiated 4 times in `top_module`, hand-wired. Passes a self-checking testbench against Python golden vectors.

- Real connectome loaded in Python: 300 neurons, 3,669 chemical connections + 75 one-way "circuit pipe" links, 1,087 pipes (Cook 2019 wiring, Fenyves 2020 signs). Settings: `K = 10`, `SIGN_ORDER = circuit → table → gaba`, table "complex" → −, `pipe_shift = 10`, `PIPE_K = 1`.
- Sign rules: `CIRCUIT` tags 53 neurons with (team, layer): touch sensors, command neurons, motor neurons (DA/VA backward, DB/VB forward). `circuit_rule`: only downstream or command ↔ command; same team → +, opposite → −; anything else → None (table decides).
- Circuit pipes: each pipe between a command neuron and a motor on its own team is also added as a one-way connection (command → motor, `size * K`), so commands can drive their motors without the motors pushing back (no ping-pong).
- Touch test passes both ways: head poke → backward commands and backward motors, tail poke → forward commands and forward motors, brain goes quiet after each poke. Backward motors respond about 2x more than forward (AVA's dense wiring); left as is on purpose to avoid overfitting.
- Robot readout works in Python (`touch_test.ipynb`): head poke → wheels backward (steps 10–31, top speed ~51), tail poke → wheels forward (steps 49–66, top speed ~20), never the wrong way, stops on its own.
- Pipes (with spike packages) are in Python only, not in Verilog yet.

## Model conventions (Python and Verilog must match exactly)
- Integer-only LIF: `v = v - (v >> 3) + total`; spike if `v >= 256`, then reset `v = 0`.
- `total` (this step's input, reset to 0 each step) is kept separate from `v` (neuron memory). The leak uses the old `v` before input is added.
- Neuron-to-neuron spikes arrive with a **one-step delay** (from `last_spikes`). Pokes (external inputs) act on the **same step**.
- Sparse format: `connections[sender] = [(receiver, weight), ...]`; `poke_connections[poke] = [(receiver, weight), ...]`.
- Chemical weights are pre-scaled by the parser (`size * K`, signed), so the model just adds them. The one-way circuit pipe links are stored in `connections` the same way, so the model loop doesn't treat them differently.
- Robot readout (muscle buckets): the generated file exports `back_motors` (DA/VA indices) and `forward_motors` (DB/VB indices). Each step, after the neurons update: leak both buckets first (`muscle = muscle - (muscle >> MUSCLE_LEAK)`, `MUSCLE_LEAK = 2`), then add +1 per motor in that group that fired. Decide: both below `STOP_BELOW = 8` → `("stop", 0)`; otherwise the bigger bucket wins, speed = difference between the buckets. Buckets never reach 0 with integer shifts (stuck at 3), so stop uses a cutoff.
- Pipes (gap junctions): `pipes = [(a, b, size), ...]`, each pair once, raw size. Each step, two jobs, both written into `totals` (never `voltages`):
  - Flow: `flow = ((voltages[a] - voltages[b]) * size) >> pipe_shift`, from start-of-step voltages; `totals[a] -= flow`, `totals[b] += flow`.
  - Spike packages: if `last_spikes[a]`, `totals[b] += size * PIPE_K`; if `last_spikes[b]`, `totals[a] += size * PIPE_K` (always +, one-step delay like chemical spikes).
  - Needed because a firing neuron resets to 0, so flow alone can't pass on that it fired. Keep `size * PIPE_K` small: two-way + pipes can ping-pong forever (`PIPE_K` 3 and up runs away).
- 4-neuron test network: indices A=0, B=1, C=2, I=3. Weights: A→B 300, B→C 300, I→B −400; poke 0 → A 300, poke 1 → I 300.
- Golden outputs (6 files): `chain_inputs.txt` (`row[0]*2 + row[1]`), `chain_expected_spikes.txt` (`A*8 + B*4 + C*2 + I`), and `chain_expected_va/vb/vc/vi.txt` (16-bit masked, `%04x`).
- Verilog wiring: `spikes_in` is 3 bits, with `[2]` = WEIGHT_ONE input.

## Verification rule
Any change to the Python model must reproduce the existing golden files exactly unless the math is changed on purpose. If the math changes, change Python first, then Verilog, then regenerate golden files.

## Known issues
- Python ints don't overflow; wrap/saturation should be modeled inside `neuron_model`, not only masked at export.
- Verilog: 16-bit `total`/`voltage` with no saturation; no voltage floor.
- One module instance per neuron won't scale to 302.
- Most real C. elegans neurons use graded potentials, not spikes. LIF is a deliberate simplification. Because a firing neuron resets to 0, pipes can't pass activity well; spike packages and circuit pipe links are workarounds.
- Only one behavior test so far (head + tail touch). Risk of tuning to that one test (overfitting): add more tests before tuning further.
- Pushback margin: forward motors push about +30/step back into AVBL (settles ~240, threshold 256). Rerun the head + tail test after changing `K` or `PIPE_K`.
