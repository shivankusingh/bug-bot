How it works

From a touch to the wheels

Every dot above is one of the worm's 300 neurons, and every faint line is a real connection mapped from electron microscope images. Nothing is scripted: each spark is a spike from my model traveling down one of those connections.

  1. Touch

    A poke switches on the worm's touch sensors: ALML, ALMR and AVM at the head, PLML, PLMR and PVM at the tail.

  2. Neurons

    Each neuron is an integer leaky integrate-and-fire unit. Every step it loses an eighth of its voltage (v − (v >> 3)), adds its input, and fires when it reaches 256. Then it resets to 0. It can never drop below −512.

  3. Decision

    Four backward command neurons (AVA, AVD) and four forward ones (AVB, PVC) compete. A head touch drives the backward team and blocks the forward team. A tail touch does the opposite.

  4. Wheels

    The command neurons drive 21 backward and 18 forward motor neurons. A small readout turns their spikes into wheel speed with a leaky "muscle" that smooths out the bursts, so the robot backs away from a head touch and drives off from a tail touch.

The wiring comes from Cook et al. 2019, the full map of both worm sexes. Each connection's strength is its synapse count times 10. Whether a connection excites or inhibits comes from receptor data (Fenyves et al. 2020).

Where the data can't decide, I use known biology: touch neurons block the opposite direction (Chalfie et al. 1985), command neurons on the same team help each other, and opposite teams block each other.

It's a simplified model. Most real worm neurons use smooth voltages rather than spikes, and the backward response here is about twice as strong as the forward one because AVA's wiring to its motors is that much denser. I left that as the data gives it instead of tuning the model to one test.

From Python to chip

Built to run on an FPGA

The model only uses integer math and bit shifts, and every voltage stays between −512 and 255, so it maps straight onto hardware. The Python version is the reference: its output is saved as golden files, and the Verilog version has to match them bit for bit.

Next is a time-multiplexed core: one neuron circuit that loops over all 300 neurons, with the wiring stored in on-chip memory. The whole brain needs about 110,000 bits, which fits in a small FPGA.
